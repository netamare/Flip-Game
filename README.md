# Neon Nexus

A small futuristic memory game. Flip cards, find the matching symbols, and try to finish before the timer runs out.

Choose Easy, Medium, or Hard. Matching cards in a row builds a combo and boosts your score. You also get one Time Freeze and one Neural Scan each game.

## Run it

```bash
npm install
npm run dev
```

Your best scores and sound preference are saved in your browser.
